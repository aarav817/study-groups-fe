# Study Groups Frontend
The web client for Study Groups, a collaborative platform allowing students to discover groups, coordinate study sessions, share coursework materials, and communicate in real time.
Corresponding API: [study-groups-api](https://github.com/aarav817/study-groups-api)
## Tech Stack
- **Framework:** Next.js 15, React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Railway
- **Database:** Redis, PostgreSQL
## Core Features
- **Authentication:** Session tokens and management, login, registration, and email verification on account creation.
- **Group Management:** Group discovery, creation, search, and role-based permissions (Owner, Admin, Member).
- **Resource Repository:** Hierarchical folder structure for uploading and organizing study materials specific to a group.
- **Calendar & Events:** Ability to create group events, view attendees, and plot events on a calendar view.
- **Discussions:** Group discussion text channels and direct messaging.
- **Admin Dashboard:** Traffic monitoring, worker request analytics, and system statistics.
